## 本轮修复与保留限制

- 备份表单补齐 Ant Design model，修复按钮未触发提交。
- Worker 客户端在 JSON 协议边界序列化命令，修复 Vue 响应式快照无法结构化克隆。
- 锁定/退出清空历史搜索词与清理名称引用；不允许未核对的恢复/清理请求被新的历史/清理动作替代。
- 错误或过期预检不写空库；本机候选暂存失败则不提交，候选确认失败不静默丢弃。
- 清理是从当前快照移除条目。其他尚在保留期的历史、已有备份和本机草稿不会随之删除；修改主密码也不能撤销别人已取得的旧备份。
- 浏览器扩展、恶意终端、篡改的页面脚本及完整在线服务器控制不在保护承诺内。网页代码来源可信是本模型的前提，与 PRD 8.1 一致。
- 浏览器存储被拒绝、磁盘满、真机和屏幕阅读器的完整端到端专项未在本轮执行；M4 的异机整站恢复、容量/性能与公开部署运维验收继续单列。

## 本地新增恢复密钥的实现自查（尚未发布）

第 69 节新增功能不包括在 15:53 的生产发布与此前用户确认内。Worker 用随机 32 字节恢复密钥加密已有数据密钥，以固定版本/用途/身份的关联数据认证；设置时核验当前主密码并重新输入恢复密钥，重置先认证当前 payload，再生成主密码包装。使用现有 libsodium AEAD/keygen，没有新增依赖。恢复明文只用于显示、用户主动下载和 Worker 输入，不自动进入 IndexedDB/网络/日志；恢复包装和请求候选是密文。该恢复密钥等价于第二把解密凭据，丢失或泄露的影响在页面明确显示。

服务端继续使用 WEB 会话、CSRF/Origin、严格格式、同账户锁、原子事务、版本和幂等检查；只接受配置原快照不变、重置 payload/身份不变。服务器不持有恢复秘密，不能验证或证明不受信任客户端确实拥有恢复密钥，也不能对恶意客户端提交的随机包装保证可解；可信页面代码仍是模型前提。重置不自动关闭其他已解锁页面或轮换数据密钥；旧数据库备份中的恢复包装及已获得的数据密钥不能远程撤销，独立口令备份不包含在线恢复配置。
