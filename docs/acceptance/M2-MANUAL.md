## 需要你实际确认的操作

| 项目 | 操作与预期 | 用户结果 |
| --- | --- | --- |
| 日常使用 | 双击启动并配对，关闭网页后开始监听；本地新建/编辑笔记和图片，再开网页核对。网页编辑后手动同步，本地文件更新；暂停和重启后均不会自行恢复监听。 | 待确认 |
| 范围与已有目录 | 选择两个服务器目录，在未绑定的已有本地目录配对；先查看预检，取消时文件不变，确认后按完整库内路径合并，同路径不同内容保留双方。取消某个范围后两端文件保留。 | 待确认 |
| 手动处理冲突 | 先同步共同版本，暂停后分别在网页和本地修改，再同步产生冲突。选中待处理项，打开处理窗口，核对两栏版本；暂不处理不会改文件。分别尝试保留服务器、采用冲突副本和 Markdown 手动合并。原始副本保留。 | 待确认 |
| 合并草稿 | 编辑合并内容后关闭并保存本机草稿，正常退出助手，再打开同一配置/冲突，应能继续编辑。保存合并结果才提交服务器；打开处理窗口后再从网页修改，旧选择应被拒绝。 | 待确认 |
| 删除与恢复 | 在独立测试笔记上做文件删除，数量/比例超阈值时核对应用内预览再确认；查看服务器回收站和助手状态目录的 recycle。删除与修改冲突时，修改内容应保留；采用本地可明确恢复原单文件。 | 待确认 |
| 状态与记录 | 网页设备行打开冲突记录，切换待处理、已处理记录、同步记录；核对路径、时间、处理选择和分页。暂停、退出及离线状态不能被误认成全端同步成功。 | 待确认 |
