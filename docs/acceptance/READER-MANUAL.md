# 书籍阅读模式：人工确认

本功能仅本地开发，尚未发布生产。首版为现有网站的手机浏览器适配，支持 TXT、可重排 EPUB 2/3 和 Markdown；不新增原生 App、PWA 或常驻服务。使用普通测试书籍，不用秘密验证。

## 入口

正常启动项目，打开 http://127.0.0.1:5173/ 并登录，左侧主导航进入“阅读”。书籍目录现在独立管理，不自动列出笔记目录或所有 TXT/EPUB。先新建书籍分类，再在笔记中右键 TXT、EPUB 或 Markdown 选择“复制到书架”，确认目标书籍目录；也可在阅读页直接上传。该操作建立源文件引用，正文仍为同一文件，搜索书籍名称/源路径，每页 10 本、超高内部滚动。点击书目阅读，点击“返回书目”返回。

笔记内 TXT/Markdown 保留普通编辑，原“书籍阅读模式 / 返回编辑”入口已移除；尚未加入的 EPUB 提示先加入，已加入的可转阅读页。现有进度按同一文件 ID 恢复，升级会保留已有实际阅读记录的书籍入口，不导入其他笔记。书籍只读最大 50 MiB，TXT 编辑与 Markdown 笔记仍限 1 MiB，不需要 ONLYOFFICE。

## 手动核对

阅读页使用“新建目录”“上传书籍”，笔记右键使用“复制到书架”，正文工具栏为“章节目录”。核对新建、上传、复制弹窗底部按钮的四周留白及按钮间距；窄屏不得贴边或裁切。点击遮罩不能关闭，手动关闭/提交规则保留。

手机沉浸模式：进入后工具栏默认收起，仅保留简洁进度与“菜单”。点正文/菜单唤出，点正文/收起按钮关闭，展开收起不应使正文跳动。滑动和长按选择文字不能误触；菜单可退出沉浸、打开目录/设置和切换章节。护眼/浅色/夜间主题下，按钮、目录、设置面板和下拉框颜色保持协调。需在真机核对安全区、长按选字、横竖屏和退出系统全屏；桌面 375px 截图不等同真机验收。

1. TXT 章节：用包含分卷、章节、序章、尾声的文本，打开目录并展开；正文中的“他想起第一章……”不应作为目录。搜索章节，点击定位，再次点击当前章仍可定位。没有识别到标题时提示，仍可阅读全文。标题首版偏保守，不支持手动编辑目录/自定义规则。
2. EPUB：打开有嵌套目录的普通 EPUB，核对原目录层级、章节定位、正文及库内位图；EPUB 2 NCX 与 EPUB 3 导航分别确认。缺失目录时按标注的正文文件顺序导航，不猜测章节。原书样式/字体由阅读设置统一控制，不保证固定排版还原。
3. 阅读位置：读到段落中间，待底部显示“阅读进度已保存”，关闭再打开；应回到同一段相近文字位置。换一个已登录浏览器或手机，应读取服务器进度。进度不是页面滚动像素或固定页码。
4. 排版和屏幕：调整字号、行距、字体、主题，横竖屏切换后仍定位相同文字；长篇书籍持续向上/下滚动，无明显缺段或突跳。检查最后一章能正常定位、结尾留白和上一章/下一章。
5. 手机目录：目录在页面内部滚动，当前章高亮并定位；选中章节后关闭。目录、设置通过关闭按钮退出，遮罩不直接关闭；键盘 Tab/Shift+Tab、Escape 可操作。
6. 全屏：点击全屏，在支持的浏览器进入系统全屏；工具栏仍可退出。浏览器不支持或拒绝时提示并进入沉浸模式。设置里也可单独选择沉浸模式。需在实际 Android/iPhone 浏览器核对，不将桌面窄屏截图视为真机结论。
7. 冲突：两个页面先打开同一书籍，在一个页面保存进度后，另一个再改变位置；旧页面应提示冲突，分别核对“采用服务器位置 / 采用本机位置”。不把旧页面自动覆盖为最新进度。
8. 同一文件更新：打开书籍，在另一页面编辑其源 TXT/Markdown；约 5 秒内自动检查并刷新正文，重新激活阅读页也会检查。核对新增内容、章节，以及原位置的唯一文字片段能否继续定位；删除/大幅修改原段落时应提示回到章节或正文开头。全屏中刷新不应退出全屏。改名/移动后仍引用同一文件。源文件删除时入口不可用，恢复源文件后可继续；阅读本身不发布源文件新版本。
9. 网络：断网后继续阅读当前已打开的正文，状态不得显示服务器成功；联网点击底部状态重试，核对位置。直接关闭/系统回收页面可能来不及上传，以本机暂存为恢复辅助；本版不提供离线整本书缓存。
10. 独立阅读页：核对导航高亮、真实书目、搜索及 10 本分页、列表内部滚动；本页上传使用应用确认弹窗，选择目标目录、重名拒绝、上传成功后直接阅读。切换到笔记、工作台或退出时保存位置，再回阅读页可继续；TXT 普通编辑和原文件下载正常。手机上书目、分页、上传及返回书目可操作。
11. 独立书籍目录：新建/编辑书籍分类不会改变笔记文件夹。右键“复制到书架”之后两边保持同一文件 ID；重复加入不复制。移动书籍分类不改变源路径；删除分类连同子分类或从书架移除时，确认只移除入口，源文件和进度仍存在，重新加入可继续。目录状态被其他页面改变后旧确认应被拒绝。
12. Markdown：标准标题生成目录，正文与代码以安全文字展示，库内 PNG/JPEG/WebP 插图按原笔记相对路径读取，外部自动图片被阻止；不执行原始 HTML/脚本。阅读排版不等于笔记预览的全部 Markdown 样式。

## 限制与复现

加密/DRM/混淆资源、固定版式 EPUB 不支持；不执行书内脚本、表单或 CSS，不自动请求外部图片。仅渲染文字及安全库内 PNG/JPEG/WebP/GIF，不支持 SVG、数学排版、音视频、交互内容或原书样式。EPUB 当前读取 UTF-8 XML；资源至多 5000 项、单项解压至多 16 MiB、总计至多 128 MiB，正文至多 250000 段，超限提示并保留原件。没有网页书源抓取、朗读、OCR 或左右翻页。
