# 默认技术栈偏好

## 技术偏好
- 后端第一优先：Java + Spring Boot；需要持久化时可优先评估 MyBatis-Plus。
- 后端第二优先：Python；当 AI、数据处理或生态适配明显更合适时，可以推荐 Python，并说明理由。
- 前端默认偏好：Vue 3 + TypeScript（Vue 项目优先 Composition API）；按 PRD、现有项目及适配性可推荐其他框架。
- 数据库默认偏好：MySQL；Redis 仅在明确需要缓存、队列等能力时引入。

## 选择与确认
- 已有项目优先沿用既定技术栈、依赖及版本；更换技术栈应先获得用户确认。
- 新项目必须结合 PRD、兼容性、维护与部署成本给出一个推荐选型，**所有关键技术选型均须用户确认后实施**。
- Java 优先、Python 第二是默认偏好，**不是排他性限制**；明显更适合 Python 时应给出理由而非机械坚持 Java。
- 前端 Vue 3 + TypeScript 是默认偏好，**不是硬性要求**；可以根据项目选择其他前端技术。
- 版本以项目实际依赖及兼容性为准，不凭空指定版本；不为未来假设引入无用依赖。
